# expense-tracker
**Overview**
Expense Tracker API is a Spring Boot-based financial transaction management application designed to help users manage and monitor their income and expenses efficiently. The application provides RESTful APIs to create, retrieve, update, and delete financial transactions while maintaining clean layered architecture and database integration.
This project demonstrates backend development concepts including REST APIs, Spring Boot architecture, JPA/Hibernate ORM, database operations, validation logic, and CRUD functionality commonly used in enterprise financial applications.

**Business Use Case**
The application helps users:
Track income and expenses
Maintain financial transaction history
Monitor spending patterns
Store transaction details securely
Manage personal financial records digitally

**Features**
Create financial transactions
Retrieve all transactions
Retrieve transaction by ID
Update transaction details
Delete transactions
Validation for invalid transaction amounts
RESTful API architecture
Layered Spring Boot architecture
H2 in-memory database integration
JPA/Hibernate ORM support
